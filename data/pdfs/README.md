Drop scheme guideline PDFs (G.O.s, operational guidelines, FAQs) here.

Name each file starting with the scheme id from `data/schemes.yaml` so its passages are linked
to that scheme, e.g. `talliki_vandanam_GO_2025.pdf` or `pm_kisan_operational_guidelines.pdf`.
Files without a matching prefix are still searchable in free-form Q&A.

They are chunked (≈900 characters with overlap, sentence-aware) and indexed automatically on the
next start; explanations then cite them by file name and page.
